# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussion about the work. Harassment,
personal attacks and discrimination of any kind are not tolerated, in issues, pull requests,
discussions or anywhere else this project is discussed.

To report a problem, contact the maintainer, [@imlargo](https://github.com/imlargo), through
GitHub. Reports are handled privately and in confidence.
